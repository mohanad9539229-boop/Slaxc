في المفضلة

أهلاً بك في سلاكس سينما 🌸

تستعين سيرفرات التشغيل المجانية بإعلانات منبثقة خارجة عن إرادتنا عند الضغط على المشغل.

نصيحة لمشاهدة صافية:

نوصي باستخدام متصفح Brave أو إضافة uBlock Origin أو تفعيل AdGuard DNS.

الفلترة المتقدمة

كيفية تجنب الإعلانات المزعجة

للحصول على تجربة مشاهدة خالية من النوافذ المنبثقة نهائياً:

1. متصفح Brave (للجوال والكومبيوتر)

يمنع الإعلانات والنوافذ المنبثقة تلقائياً دون الحاجة لأي إعدادات.

2. إضافة uBlock Origin

أفضل إضافة حظر إعلانات متوفرة لمتصفحات سطح المكتب.

3. AdGuard DNS (للأيفون والأندرويد)

في إعدادات الـ DNS بالجوال اكتب: dns.adguard.com

إعدادات TMDB API

كيفية الحصول على مفتاح TMDB API:

  1. قم بإنشاء حساب على موقع TMDB.
  2. انتقل إلى إعدادات الحساب (Account Settings) ثم اختر API.
  3. اضغط على Create ثم اختر Developer.
  4. انسخ API Key (v3 auth) وضعه في الخانة أعلاه.
